# Быстрый старт

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

1. Создай файл `.env` на основе `env.example`:
```bash
cp env.example .env
```

2. Добавь токен своего бота в `.env`:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

3. Убедись, что запущен Ollama (для AI-ассистента):
```bash
ollama serve
```

## Запуск бота

```bash
python main.py
```

## Доступные команды

### Персонажи
- `/createcharacter` - создать нового персонажа (пошаговый процесс)
- `/mycharacters` - список твоих персонажей

### Справочники
- `/races` - список всех рас D&D
- `/classes` - список всех классов
- `/spells` - книга заклинаний

### Обучение
- `/rules` - основные правила D&D
- `/dice` - система бросков кубиков
- `/combat` - правила боя
- `/stats` - объяснение характеристик
- `/glossary` - словарь терминов

### Помощь
- `/start` - приветствие
- `/help` - справка по командам

## Процесс создания персонажа

1. Отправь `/createcharacter`
2. Введи имя персонажа
3. Выбери расу (с пагинацией)
4. Выбери класс (с пагинацией)
5. Выбери предысторию (с пагинацией)
6. Выбери метод генерации характеристик:
   - Стандартный набор (15, 14, 13, 12, 10, 8)
   - Случайная генерация (4d6, отбросить низший)
   - Покупка очков (27 очков, диапазон 8-15)
7. Распредели характеристики
8. Выбери заговоры (для заклинателей)
9. Выбери заклинания 1 уровня (для заклинателей)
10. Выбери навыки класса
11. Просмотри персонажа и подтверди сохранение

Все данные сохраняются автоматически!

## Устранение неполадок

### Бот не отвечает
- Проверь, правильно ли указан токен в `.env`
- Убедись, что бот запущен: `python main.py`

### Ошибки импорта
- Установи зависимости: `pip install -r requirements.txt`

### Персонажи не сохраняются
- Проверь, существует ли директория `data/characters/`
- Создай её вручную, если нужно

### AI-ассистент не работает
- Убедись, что Ollama запущен: `ollama serve`
- Проверь, установлена ли модель: `ollama pull llama2`
