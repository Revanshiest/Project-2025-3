## 📋 Процесс создания персонажа

### Этапы:
1. **START** → Команда `/createcharacter`
2. **NAME** → Ввод имени персонажа (текстом)
3. **RACE** → Выбор расы (с пагинацией)
4. **CLASS** → Выбор класса (с пагинацией)
5. **BACKGROUND** → Выбор предыстории (с пагинацией)
6. **ABILITIES_METHOD** → Выбор метода генерации характеристик
7. **ABILITIES_ASSIGN** / **ABILITIES_POINT_BUY** → Распределение характеристик
8. **SPELLS_CANTRIPS** → Выбор заговоров (для заклинателей)
9. **SPELLS_KNOWN** → Выбор заклинаний 1 уровня (для заклинателей)
10. **SKILLS** → Выбор навыков класса
11. **REVIEW** → Просмотр и подтверждение
12. **COMPLETE** → Сохранение персонажа

### Автоматические расчёты:
- Применение расовых бонусов к характеристикам
- Расчёт модификаторов характеристик
- Расчёт хитов (максимум кости + бонус Телосложения)
- Применение владений класса (доспехи, оружие, инструменты)
- Применение способностей класса 1 уровня
- Настройка заклинательных способностей (ячейки, DC, бонус атаки)

## 🎮 Callback паттерны

Все callback для создания персонажей начинаются с префикса `char_`:

- `char_create_new` - начать новое создание
- `char_continue` - продолжить незавершённое создание
- `char_restart` - перезапустить создание
- `char_create_cancel` - отменить создание
- `char_race_{race_name}` - выбор расы
- `char_race_page_{page}` - пагинация рас
- `char_class_{class_id}` - выбор класса
- `char_class_page_{page}` - пагинация классов
- `char_bg_{bg_id}` - выбор предыстории
- `char_bg_page_{page}` - пагинация предысторий
- `char_abilities_standard` / `_roll` / `_pointbuy` - метод генерации
- `char_assign_{ability}` - начать назначение характеристики
- `char_assign_{ability}_{score}` - назначить значение
- `char_abilities_reset` - сбросить распределение
- `char_abilities_confirm` - подтвердить характеристики
- `char_pb_{ability}_inc` / `_dec` - изменить очки покупки
- `char_pb_reset` - сбросить покупку очков
- `char_skill_{skill}` - выбор навыка
- `char_skills_confirm` - подтвердить навыки
- `char_cantrip_{cantrip}` - выбор заговора
- `char_cantrip_page_{page}` - пагинация заговоров
- `char_cantrips_confirm` - подтвердить заговоры
- `char_spell_{spell}` - выбор заклинания
- `char_spell_page_{page}` - пагинация заклинаний
- `char_spells_confirm` - подтвердить заклинания
- `char_save` - сохранить персонажа
- `char_view_{char_id}` - просмотр персонажа
- `char_delete_{char_id}` - запрос на удаление
- `char_delete_confirm_{char_id}` - подтверждение удаления
- `char_list` - вернуться к списку персонажей

## 💾 Хранение данных

### Структура файла `data/characters/user_{user_id}.json`:
```json
[
  {
    "id": "user_id_timestamp",
    "user_id": 123456789,
    "name": "Арагорн",
    "race_key": "ЧеловекHuman",
    "race_name": "Человек",
    "class_id": "fighter",
    "class_name": "Воин",
    "level": 1,
    "strength": 16,
    "dexterity": 14,
    ...
  }
]
```

### Сессии создания:
- Хранятся в памяти в словаре `_creation_sessions` модуля `character_creator.py`
- Автоматически удаляются после сохранения или отмены
- Ключ: `user_id`

## 🔧 Особенности реализации

1. **Проверка незавершённого создания**: При `/createcharacter` проверяется существующая сессия с предложением продолжить или начать заново

2. **Интеграция с существующими модулями**:
   - Использует `character_creator.py` для базовой логики персонажей
   - Использует `character_data.py` для загрузки рас, классов, предысторий
   - Все расчёты производятся существующими функциями

3. **Обработка ввода имени**: 
   - В `handle_message` добавлена проверка состояния сессии
   - Если пользователь на этапе NAME, текст обрабатывается как имя персонажа

4. **Пагинация**:
   - Все длинные списки разбиты на страницы по 8-10 элементов
   - Кнопки навигации: ⬅️ Назад / Стр X/Y / Вперёд ➡️

5. **Заклинания**:
   - Автоматическое определение, является ли класс заклинателем
   - Разные логики для классов с известными заклинаниями, подготовленными заклинаниями и книгой заклинаний
   - Волшебник получает 6 заклинаний в книгу на 1 уровне

6. **Валидация**:
   - Проверка длины имени (2-50 символов)
   - Проверка существования выбранных рас/классов/предысторий
   - Проверка корректности распределения очков при покупке

## 🎯 Использование

### Создание персонажа:
```
Пользователь → /createcharacter
Бот → Приветствие и запрос имени
Пользователь → "Арагорн"
Бот → Список рас с кнопками
Пользователь → Нажимает "Человек"
Бот → Список классов
...
Бот → Финальный просмотр персонажа
Пользователь → "✅ Сохранить персонажа"
Бот → "✅ Персонаж Арагорн сохранён!"
```

### Просмотр персонажей:
```
Пользователь → /mycharacters
Бот → Список всех персонажей с кнопками
Пользователь → Нажимает на имя персонажа
Бот → Полная информация о персонаже
```
